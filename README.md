# 方块空间

一个无需第三方依赖的经典俄罗斯方块 Web 游戏。包含方块生成、移动、旋转、加速/直接下落、消行计分、等级加速、暂停、结束与重新开始，并针对小屏幕提供了触控按钮。

## 本地启动

需要 Python 3 或 Node.js（仅用于运行测试）。

```bash
# 在项目目录启动静态服务器
python -m http.server 8000
```

然后在浏览器打开 <http://localhost:8000>。

也可以通过 npm 脚本启动：

```bash
npm start
```

## 操作

| 按键 | 操作 |
| --- | --- |
| `←` / `→` | 左右移动 |
| `↑` | 顺时针旋转 |
| `↓` | 加速下落 |
| `空格` | 直接落下 |
| `P` | 暂停或继续 |

每消除 10 行提升 1 级，等级越高，自动下落越快。

## 验证

```bash
npm test
```

测试覆盖棋盘初始化、碰撞检测、旋转、消行和得分规则。
